# Security and Responsible Use

This repository is an educational machine-learning project. It is not a medical device and must not be used for diagnosis, treatment decisions, or other clinical decisions.

## Reporting security issues

If you discover a security issue involving repository integrity, dependencies, notebooks, generated artifacts, or deployment content, report it privately through the maintainer's GitHub profile before publishing exploit details.

## Data and model safety

- Do not commit private medical records or personally identifiable health data.
- Use only datasets that you are authorized to access and redistribute.
- Do not present experimental model output as clinical advice.
- Document model limitations and dataset assumptions when changing evaluation code.
- Do not commit API keys, tokens, private credentials, or cloud secrets.
