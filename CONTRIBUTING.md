# Contributing

Contributions are welcome for reproducibility, evaluation quality, documentation, testing, visualization, and model-comparison experiments.

Before opening a pull request:

1. Keep the project framed as educational research, not a clinical diagnostic tool.
2. Do not add private or restricted medical data.
3. Document dataset changes and evaluation assumptions.
4. Include reproducible commands or notebook steps for new experiments.
5. Report metrics together with the evaluation split and relevant configuration.
6. Keep commits focused and explain why the change improves the project.

For major model or dataset changes, open an issue first.
